# Python End to End

A beginner-friendly Python learning notebook covering the core fundamentals of Python programming. This project is designed to help new learners understand basic Python concepts through simple examples and hands-on practice.

## Overview

This repository contains a single Jupyter notebook, `python_end2end.ipynb`, which introduces essential Python topics such as:

- Print statements and output formatting
- Data types and variables
- Keywords and identifiers
- User input and type conversion
- Literals
- Operators
- Conditional statements (`if`, `else`)
- Basic Python syntax and logic building

## Project Structure

```text

```

## Topics Covered

### 1. Print Function

Learn how to print text, numbers, booleans, and formatted output using `print()`.

### 2. Data Types

Examples of:

- Integers
- Floats
- Booleans
- Complex numbers
- Strings
- Lists
- Tuples
- Sets
- Dictionaries

### 3. Variables

Understand dynamic typing and dynamic binding in Python.

### 4. Input and Type Conversion

Practice receiving user input and converting strings into integer or float values before computation.

### 5. Literals

Explore numeric, string, boolean, and special literals used in Python.

### 6. Operators

Covers:

- Arithmetic operators
- Comparison operators
- Logical operators
- Bitwise operators
- Assignment operators
- Identity operators
- Membership operators

### 7. Control Flow

Examples of basic decision-making using `if` and `else` statements.

## Prerequisites

Before running the notebook, make sure you have:

- Python 3 installed
- Jupyter Notebook or VS Code with Python support
- A working environment for executing `.ipynb` files

## Getting Started

### Option 1: Open in VS Code

1. Open the project folder in VS Code.
2. Open `python_end2end.ipynb`.
3. Run the cells sequentially to see each example execute.

### Option 2: Run with Jupyter Notebook

```bash
jupyter notebook
```

Then open `python_end2end.ipynb` from the browser window.
